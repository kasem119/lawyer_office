# أرشيف تطبيق سطح المكتب

اختيار المشروع الحالي هو نسخة الويب. يحتوي هذا المجلد على كود Electron وإعداد التغليف السابق كما كان قبل الفصل.

- `electron/`: تشغيل سطح المكتب وpreload.
- `client-package.json`: نسخة إعدادات العميل السابقة للتوثيق والاسترجاع.
- `server/`: مراقب الخادم القديم وأيقونات Electron.
- `windows/`: أدوات التشغيل التلقائي المحلية وملفات BAT السابقة، محفوظة بمحتواها وبصماتها دون تشغيل.

هذا الأرشيف لا يدخل بناء Vite أو حزمة النشر. مساراته النسبية تاريخية ولا تُشغّل مباشرة من هذا المجلد. لا تثبت حزم Electron في واجهة الويب لإعادة تشغيله.
