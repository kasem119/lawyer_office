# سكربتات تاريخية

هذه الملفات محفوظة للرجوع إلى أعمال الإصلاح والتشخيص السابقة، ولا تُشغَّل عند البناء أو بدء التطبيق.

| المجلد | المحتوى |
| --- | --- |
| `patches/` | تعديلات نصية قديمة؛ المسارات النسبية تبدأ من جذر المشروع |
| `remote/` | أدوات تشخيص وإصلاح سابقة للخادم البعيد |
| `tests/` | اختبار API قديم يُنشئ بيانات |

راجع السكربت وإعداداته قبل استخدامه. قد يحتوي على إعدادات اتصال قديمة. استخدم أدوات `deploy/` الحالية للنشر واختبارات `server/tests/` للتحقق.

السجلات السابقة محفوظة محلياً في `artifacts/logs/`، وسجل النقل في `artifacts/organization-moves.json`.
