# اختبارات الصلاحيات وعزل المكاتب

من مجلد `server` شغّل `npm run test:permissions`.

تستخدم المجموعة التطبيق الحقيقي ورموز JWT وقاعدة SQLite في الذاكرة ومجلدات مؤقتة. لا تتصل بقاعدة الإنتاج، ولا ترسل بريدًا حقيقيًا، ولا تشغّل Chromium؛ يُستبدل البريد وتوليد PDF داخل الاختبار فقط.

تضم البيانات مكتبين ومديرين ومحامين مسؤولين ومكلفين وغير مكلفين وحسابًا معطلًا ومالك المنصة. تشمل 65 مجموعة تحقق و262 طلب HTTP:

- القوائم والوصول المباشر للقضايا والعملاء والمستندات والمواعيد والمهام والفواتير.
- منع القراءة والتعديل والحذف بين المكاتب ومنع ربط سجل بقضية غير مسموحة.
- إخفاء القضايا غير المكلف بها المحامي في تفاصيل العميل والبحث والتقارير وتصدير Excel.
- احترام الملاحظات الخاصة في تفاصيل القضية وتصدير PDF.
- مشاركة مستند دون منح صلاحية الوصول إلى القضية كاملة.
- فصل رمز بوابة الموكل عن حسابات الموظفين، والتحقق من الحساب الفعلي في قاعدة البيانات.
- فصل مالك المنصة عن بيانات المكاتب، وحصر الإشعارات بمستلمها وسجلات النشاط بالمكتب.
- منع مدير مكتب من الوصول إلى نسخ قاعدة البيانات الشاملة عند وجود أكثر من مكتب.

هذه تغطية للمسارات المذكورة، وليست تدقيقًا شاملًا لجميع ميزات النظام أو اختبار اختراق. فحص الموقع بعد النشر مستقل عن هذه الاختبارات المعزولة.

اختبارات الإصلاحات السابقة: `npm run test:improvements`، وفيها 10 تحققات للإغلاق وإرفاق الحكم ورابط البوابة ومعالجة فشل الحفظ.
