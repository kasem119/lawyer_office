# تحميل JavaScript عند الحاجة

تُحمّل شاشات الواجهة عبر `React.lazy`، مع مؤشر انتظار عام وصفحة انتظار داخل مساحة المحتوى تبقي قائمة التنقل ظاهرة. تبقى أخطاء تحميل الأجزاء ضمن `ErrorBoundary` الموجود وزر إعادة التحميل.

تُحمّل مكتبة `pdf-lib` عند إنشاء PDF من الصور فقط، داخل مسار معالجة الأخطاء الموجود. يجمع إعداد Vite مكتبات React والأيقونات في ملفين مشتركين قابلين للتخزين المؤقت، لتجنب طلب ملف صغير لكل أيقونة مشتركة.

## القياسات

بناء الإنتاج بتاريخ 2026-10-09 باستخدام Vite 6.4.3، بالكيلوبايت العشري. تشمل أحجام الصفحات كل اعتماديات JavaScript المتزامنة دون تكرار، ولا تشمل CSS أو الصور أو استجابات API.

| مسار التحميل | JavaScript | gzip |
| --- | ---: | ---: |
| قبل التقسيم: حزمة واحدة لجميع الشاشات | 1,070.44 kB | 329.34 kB |
| بعد التقسيم: بدء التطبيق والاعتماديات المشتركة | 209.85 kB | 63.43 kB |
| بعد التقسيم: بدء التطبيق مع الصفحة التعريفية | 231.77 kB | 69.78 kB |
| بعد التقسيم: بدء التطبيق مع لوحة المكتب | 280.50 kB | 81.10 kB |

انخفض JavaScript المطلوب للصفحة التعريفية بنحو 78% وللوحة المكتب بنحو 74%. هذه قياسات حجم وليست قياساً لزمن التحميل على شبكة فعلية. أصبحت هناك 24 شاشة مؤجلة، وأكبر جزء هو مكتبة PDF بحجم 437.03 kB، دون تجاوز تحذير Vite البالغ 500 kB.

## التحقق

من مجلد `client`:

```sh
npm run build
npm run test:bundle
```

يبني `test:bundle` نسخة في الذاكرة ويفحص رسم اعتماديات الإنتاج دون تغيير `dist`. يفشل إذا عادت الشاشات أو مكتبة PDF إلى التحميل المبكر، أو تجاوز بدء التطبيق 250 kB، أو الصفحة التعريفية 300 kB، أو لوحة المكتب 350 kB، أو أي جزء 500 kB.

شمل اختبار المتصفح المحلي لهذا التغيير الصفحة التعريفية والدخول والتسجيل وبوابة الموكل، ولوحة المكتب والقضايا والعملاء والمستندات، ولوحة مالك المنصة. تحقق الاختبار من بقاء التنقل ظاهراً أثناء انتظار الجزء، ومن تأجيل مكتبة PDF حتى الإرسال وإنتاج ملف PDF إلى نقطة رفع وهمية، ومن ظهور واجهة استعادة الخطأ عند تعذر تحميل جزء. استُخدمت بيانات API وهمية؛ لم يُختبر خادم الإنتاج.

الأساس التقني: [React lazy](https://react.dev/reference/react/lazy) و[تحميل الأجزاء غير المتزامن في Vite 6](https://v6.vite.dev/guide/features#async-chunk-loading-optimization).
