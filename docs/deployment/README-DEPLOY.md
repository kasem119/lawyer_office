# 🚀 دليل نشر التحديثات على السيرفر (Deploy Guide)

تم إنشاء أداة نشر موحدة وذكية لنقل التحديثات البرمجية مباشرة إلى سيرفر المنظومة المباشر (**muhami.ly / 102.203.202.104**).

---

## ⚡ طرق التشغيل السريعة

### 1. بالضغط المزدوج على ويندوز (الأسهل)
- انقر مرتين على ملف **`deploy.bat`** (أو **`نشر_التحديثات.bat`**) في المجلد الرئيسي.
- ستظهر لك قائمة تفاعلية سهلة لاختيار ما تريد نشره:
  - `[1]` نشر كامل (الواجهة الأمامية + السيرفر وقاعدة البيانات).
  - `[2]` نشر الواجهة الأمامية فقط (سريع).
  - `[3]` نشر السيرفر الخلفي وقاعدة البيانات فقط.
  - `[4]` فحص حالة السيرفر واستهلاك الموارد.
  - `[5]` عرض سجلات أخطاء السيرفر (Logs).
  - `[6]` إعادة تشغيل خدمة المنظومة على السيرفر.

### 2. عبر أوامر السطر (Terminal / PowerShell)

```bash
# نشر كامل (بناء الواجهة + رفع الملفات + تحديث قاعدة البيانات + فحص الصحة)
npm run deploy

# نشر الواجهة الأمامية فقط
npm run deploy:frontend

# نشر السيرفر فقط
npm run deploy:backend

# فحص حالة السيرفر
npm run deploy:status

# عرض آخر 50 سطر من سجلات السيرفر
npm run deploy:logs
```

### 3. عبر ملف `Makefile`

```bash
make deploy           # نشر كامل
make deploy-frontend  # نشر الواجهة فقط
make deploy-backend   # نشر السيرفر فقط
make status           # فحص السيرفر
make logs             # السجلات
make restart          # إعادة التشغيل
```

## 🛡️ ميزات الأمان والسلامة

1. **النسخ الاحتياطي التلقائي (Automatic Backup):**
   قبل استبدال أي ملف على السيرفر، يتم أخذ نسخة احتياطية تلقائياً في:
   `/opt/lawyer_office/deployment-backups/` مع الطابع الزمني.

2. **حماية قواعد البيانات والمرفقات:**
   - لا يتم استبدال أو حذف قاعدة بيانات SQLite الحية (`lawyer_office.db`).
   - لا يتم مساس مجلدات الرفع والمرفقات والنسخ الاحتياطية للمستخدمين (`uploads/`, `backups/`).
   - يتم تطبيق أي تعديلات في المخطط (Schema Migrations) تلقائياً ودون فقدان البيانات.

3. **التحقق من صحة النظام (Health Verification):**
   بعد انتهاء الرفع، تتحقق الأداة تلقائياً من endpoint الفحص:
   `https://muhami.ly/api/health`
   ولا تكتمل العملية إلا بعد التأكد من أن المنظومة تعمل بنسبة 100%.

4. **إعادة تشغيل نظيفة:**
   إعادة تشغيل خدمة `lawyer-office` وتحديث Nginx تلقائياً لضمان قراءة التحديثات الفورية دون ترك مخلفات في الكاش.

## ⚙️ إعدادات وخيارات متقدمة

يمكنك تخصيص الاتصال أو حفظ الإعدادات لتجنب طلب كلمة المرور في كل مرة:

```bash
# حفظ الإعدادات واستخدام مفتاح SSH
python deploy/deploy.py --host 102.203.202.104 --user root --key C:\Users\user\.ssh\id_rsa --save-config

# تخطي إعادة بناء الواجهة (إذا كانت مبنية بالفعل في client/dist)
python deploy/deploy.py --mode frontend --skip-build

# عرض عدد أسطر أكبر من السجلات
python deploy/deploy.py --mode logs --lines 100
```
