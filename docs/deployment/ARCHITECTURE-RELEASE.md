## مسار النشر

```powershell

python deploy/deploy_review_release.py smoke --architecture
```

هذه حزمة للملفات المحددة في قائمة architecture داخل الأداة؛ حدّث القائمة عند إضافة وحدة أخرى. يعتمد الاتصال على هوية SSH مثبتة وبيانات Windows Credential Manager، ولا يطبع الأسرار أو يحفظ رموز فحوص الجلسة. النشر يجهز التبعيات قبل إيقاف الخدمة ويدعم الرجوع عند فشل التحقق.
