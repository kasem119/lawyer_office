# 📖 دليل نشر منظومة مكتب المحاماة على الإنترنت

هذا الدليل ينقلك من الوضع الحالي (خادم على جهاز المكتب) إلى نظام متاح من أي مكان في العالم عبر دومين حقيقي مع HTTPS، يعمل على الكمبيوتر واللابتوب والهاتف.

**التكلفة الشهرية المتوقعة:** خادم VPS ≈ 5–10$ + دومين ≈ 1–2$ شهرياً (تُدفع سنوياً) + شهادة SSL مجانية.

---

## الجزء الأول: الشراء

### 1. شراء خادم VPS
اختر أحد هؤلاء المزودين (أي خطة بمواصفات: **2 vCPU، 4GB RAM، 60GB SSD، أوبونتو 24.04**):

| المزود | الخطة المناسبة | السعر التقريبي |
|--------|----------------|----------------|
| [Hetzner](https://www.hetzner.com/cloud) | CX22 | ~4€/شهر |
| [Contabo](https://contabo.com) | Cloud VPS 1 | ~5$/شهر |
| [DigitalOcean](https://www.digitalocean.com) | Basic 4GB | ~24$/شهر |

**عند الإنشاء:**
- الموقع: أقرب مدينة لمكتبك (فرانكفورت/أمستردام للشرق الأوسط جيدة).
- النظام: Ubuntu 24.04 LTS.
- فعّل ميزة "Backup" لدى المزود (نسخ احتياطي يومي من المزود، احتياط إضافي ~20% من السعر).

بعد الإنشاء ستحصل على **IP عام** مثل `95.216.100.50` ورسالة تحتوي كلمة مرور `root`. سجّلها.

### 2. شراء الدومين
من أي مسجل: [Namecheap](https://namecheap.com)، [Cloudflare](https://www.cloudflare.com/products/registrar/)، أو مسجّل محلي (أرخص في فلسطين/الأردن للامتدادات المحلية مثل `.ps`).

اختر اسماً قصيراً سهل الإملاء، مثلاً: `myfirm.com` أو `office.myfirm.ps`.

### 3. ربط الدومين بالخادم (DNS)
في لوحة تحكم الدومين أضف سجل **A** واحد:

| النوع | الاسم | القيمة | TTL |
|------|------|--------|-----|
| A | @ أو office | IP الخادم (مثل 95.216.100.50) | 3600 |

انتظر 15 دقيقة – ساعتين حتى ينتشر. تحقق من الانتشار بموقع [dnschecker.org](https://dnschecker.org) بكتابة دومينك.

## الجزء الثاني: تجهيز الحزمة من جهاز المكتب

على جهاز المكتب (ويندوز)، من مجلد المشروع:

```powershell
# 1) بناء الواجهة وتجهيز حزمة التطبيق
powershell -ExecutionPolicy Bypass -File deploy\pack-deployment.ps1

# 2) تجميع بيانات المكتب الحالية (قاعدة البيانات + المرفقات)
powershell -ExecutionPolicy Bypass -File deploy\migrate-data.ps1
```

سيكون لديك ملفان للرفع:
- `deploy/lawyer_office.zip` — التطبيق نفسه.
- `deploy/data_migration.zip` — بياناتك الحالية.

> ⚠️ قبل `migrate-data.ps1`: أوقف خادم المكتب حتى لا تُنسخ قاعدة SQLite أثناء الكتابة (السكربت سينبهك).

## الجزء الثالث: تجهيز الخادم

### 1. الدخول الأول
```bash
ssh root@SERVER_IP
# أدخل كلمة المرور التي وصلتك بالبريد
```

### 2. رفع الحزم من جهاز المكتب (مرة واحدة، من ويندوز)
```powershell
scp deploy\lawyer_office.zip root@SERVER_IP:/tmp/
scp deploy\data_migration.zip root@SERVER_IP:/tmp/
```

### 3. تشغيل سكربت الإعداد
على الخادم:
```bash
# انسخ ملفات الإعداد من مجلد deploy في المشروع إلى الخادم أيضاً:
scp deploy/*.sh deploy/*.conf deploy/*.service root@SERVER_IP:/tmp/   # من ويندوز

# على الخادم:
bash /tmp/setup-vps.sh office.myfirm.com
```

السكربت يتولى تلقائياً: تحديث النظام، تثبيت Node.js 22 وNginx وfail2ban، إنشاء مستخدم خدمة محدود الصلاحيات، جدار حماية يسمح فقط بـ 22/80/443، توليد مفاتيح سرية قوية، وتشغيل التطبيق كخدمة systemd تعيد التشغيل تلقائياً عند أي عطل.

### 4. إصدار شهادة SSL (مرة واحدة)
```bash
apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d office.myfirm.com --non-interactive --agree-tos -m admin@myfirm.com
```

الشهادة تتجدد تلقائياً (certbot يضيف مؤقتاً للتجديد). تحقق بـ:
```bash
certbot renew --dry-run
curl -s https://office.myfirm.com/api/health
```

### 5. استرجاع بيانات المكتب
اتبع التعليمات المطبوعة من سكربت `migrate-data.ps1` (إيقاف الخدمة، فك ضغط النسخة الاحتياطية فوق `/opt/lawyer_office/server`، إعادة التشغيل).

بعد الاسترجاع: سجّل الدخول من المتصفح على `https://office.myfirm.com` وتأكد أن القضايا والموكلين والمرفقات كلها موجودة.

## الجزء الرابع: تشغيله كتطبيق على الهاتف (PWA)

1. افتح `https://office.myfirm.com` من كروم (أندرويد) أو سفاري (آيفون).
2. سجّل الدخول.
3. **أندرويد:** قائمة ⋮ → "إضافة إلى الشاشة الرئيسية" / "تثبيت التطبيق".
   **آيفون:** زر المشاركة ⬆️ → "إضافة إلى الشاشة الرئيسية".
4. ستظهر أيقونة المنظومة كأي تطبيق، تعمل بملء الشاشة بدون شريط المتصفح.

**تصوير مستند ورقي وإضافته لقضية:**
1. افتح القضية → "إضافة مستند" → تبويب "📷 تصوير مستند".
2. اضغط زر التصوير — تفتح كاميرا الهاتف مباشرة.
3. صوّر صفحة صفحة (يمكن التدوير أو الحذف قبل الرفع).
4. اضغط "رفع كمستند PDF" — تُدمج الصور في PDF واحد وتُرفع على القضية.

**الماسح الضوئي المكتبي** يعمل كما هو: امسح ببرنامج الماسح المعتاد، ثم اسحب ملف PDF إلى تبويب "رفع ملف".

## الجزء الخامس: التحديث والصيانة

### تحديث التطبيق لاحقاً (نسخة جديدة من الكود)
```powershell
# على جهاز المكتب:
powershell -ExecutionPolicy Bypass -File deploy\pack-deployment.ps1
scp deploy\lawyer_office.zip root@SERVER_IP:/tmp/
```
```bash
# على الخادم:
systemctl stop lawyer-office
unzip -o /tmp/lawyer_office.zip -d /opt/lawyer_office
# احتفظ بملف .env الموجود وقاعدة البيانات (unzip لا يحذف شيئاً افتراضياً)
chown -R lawyer:lawyer /opt/lawyer_office
systemctl start lawyer-office
```
المستخدمون على الهاتف سيرون شريط "يوجد إصدار جديد — تحديث الآن" تلقائياً بعد إعادة فتح التطبيق.

### مراقبة الأعطال
```bash
systemctl status lawyer-office        # حالة الخدمة
journalctl -u lawyer-office -f        # السجلات المباشرة
journalctl -u lawyer-office --since "1 hour ago"
```

### النسخ الاحتياطي على الخادم
النظام يأخذ نسخة احتياطية يومية تلقائية داخل الخادم (قاعدة + مرفقات معاً في ZIP، آخر 30 نسخة).
للحماية الكارثية (حرق/فقدان الخادم كاملاً) أنصح بواحدة من:
- تفعيل خاصية Backup من مزود VPS، أو
- إضافة `CLOUD_BACKUP_DIR` في `/opt/lawyer_office/server/.env` لتوجيه نسخة على قرص تخزين خارجي mount على الخادم (S3/Google Drive عبر rclone)، أو
- تنزيل نسخة أسبوعياً على جهاز المكتب من شاشة "النسخ الاحتياطي" داخل النظام (موجودة أصلاً).

### إذا انقطع الخادم عن العمل
1. `systemctl status lawyer-office` — إن كانت الخدمة متوقفة: `systemctl start lawyer-office`.
2. إن كانت تعمل والمشكلة في الدومين: تحقق من DNS عبر dnschecker.org.
3. من لوحة مزود VPS: أعد تشغيل الجهاز، وإن تعطل القرص استعد آخر نسخة احتياطية من المزود.

## أسئلة شائعة

**هل تبقى نسخة المكتب المحلية تعمل؟** نعم، أنصح بإبقائها متوقفة لكن جاهزة لأسابيع أولى كطوارئ. البيانات عندها قديمة بعد الترحيل، فلا تعمل عليها بالتوازي.

**هل يكفي SQLite؟** نعم تماماً لحجم مكتب محاماة (آلاف القضايا) — الخادم يستخدمها بوضع WAL آمن للتزامن.

**هل يحتاج الموكلون رابطاً منفصلاً؟** بوابة الموكل موجودة أصلاً بنفس النظام وتعمل عبر نفس الرابط.

**كيف أضيف مستخدماً جديداً؟** من النظام: إدارة المستخدمين → إضافة — نفس الطريقة السابقة، لا شيء تغيّر.

**هل يمكن لاحقاً تطبيق أندرويد حقيقي في Google Play؟** نعم — الكود الحالي قابل للتغليف عبر Capacitor دون إعادة كتابة، القرار مؤجل ولا يؤثر على شيء الآن.
